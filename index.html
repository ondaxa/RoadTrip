    Location blocked? Set it by hand:

    Distance to the next stop is a straight-line estimate padded for roads, then divided by ~60 mph — a gut check, not navigation. For real turn-by-turn, use the Maps buttons on each leg above.

    Real directions vs. this planner. The map draws the actual road route and real drive times from a free routing service (OSRM). For live, turn-by-turn navigation with traffic, the per-leg Open in Google / Apple Maps buttons launch your phone's map app — that's the right tool on the road.

    Saving & moving data. Everything saves to this browser on this device. Use Export / Import to carry numbers between your phone and laptop. Your EIA key is stored separately and is never included in the export. Reset all restores defaults.

    If something won't load. Real roads and live gas need internet and the data providers allowing browser requests; opening the file straight from disk on some desktop browsers can block them. The page still works fully on estimates and manual entry. Map data © OpenStreetMap, routing by OSRM, prices by U.S. EIA.
